# Ink Tattoo Web & API

## ENV file variables

| Name | Value (default) |
| ------ | ------ |
| DB_NAME | Datebas namer |
| DB_USER | Database username |
| DB_PASS | Database password |
| DB_HOST | Database hostname |
| DB_CHARSET | utf8 |
| SITE_URL | baseurl |
| ADMIN_URL | admin url |
| API_URL | api url |
| APP_NAME | project name or app name |
| SMTP_HOST | Email smtp host |
| SMTP_PORT | Email smtp port |
| SMTP_USER | Email smtp username |
| SMTP_PASS | Email smtp password |
| EMAIL_FROM | From name on email |
| EMAIL_REPLY_TO | reply to email address |
| EMAIL_FROM_NAME | reply to name |
| ENVIRONMENT | DEV or PROD |
| PAYMENT_TYPE | DEV or PROD |
