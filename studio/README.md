# INK Studio

ממשק אחד לניהול האפליקציה, צפייה בטבלאות הגולמיות, ומעקב הכנסות/הוצאות.

## הרצה

```bash
cd studio
npm start
```

פתח רק את http://127.0.0.1:4173

- **ניהול** — ממשק Node חדש (משתמשים, דיווחים, בקשות, הגדרות). ממשק ה-PHP נשאר בגיבוי תחת "ממשק PHP ישן"
- **טבלאות** — ארכיון SQL מ-`data/` או MySQL חי מ-`app/api/.env`
- **הכנסות והוצאות** — מדדים בעברית + עריכת עלויות תפעול
